# GitHub MCP setup

En kolay kurulum için `START_HERE_GITHUB_MCP.md` dosyasını okuyun.

Windows'ta tek seferlik kurulum için `SETUP_GITHUB_REPO_BRIDGE.bat` dosyasına çift tıklayabilirsiniz.

Bu bridge yalnızca iki MCP aracı açar:

- `github_whoami`
- `create_repository`

Repo silme aracı yoktur. Repo oluşturma varsayılan olarak private'dır; public repo oluşturma ayrıca kapalıdır.
